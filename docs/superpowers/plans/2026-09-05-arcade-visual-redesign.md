# 星港游戏厅首页视觉重做计划

> **For agentic workers:** 本计划在当前会话内执行，逐项验证后发布。

**Goal:** 将星港游戏厅入口从密集的机台列表重做为有空间层次、可快速浏览、具有独立品牌识别度的深夜宇宙港街机店首页。

**Architecture:** 保留所有现有游戏入口 URL 与机台数据，不改独立游戏内容。重写 `arcade.html` 的视觉层与页面结构：以一个“深夜港口大厅”Hero 为入口，精选机台采用主展台，其余游戏按类型分组为可扫描的目录；用数据属性和现有单一点击脚本维持导航。同步 `index.html`，避免根域首页与 `/arcade.html` 视觉分裂。

**Tech Stack:** 原生 HTML/CSS/JavaScript；无外部依赖；使用本地字体与 CSS 图形；响应式移动端优先；支持 `prefers-reduced-motion`、键盘焦点与低带宽加载。

## Global Constraints

- 不删除或改变现有独立游戏入口 URL。
- 不修改各独立游戏页面，只改游戏厅入口页面。
- 不新增外部 CDN、追踪脚本或图片依赖。
- 首页首屏必须明确显示“星港游戏厅”和“选择一台机台开始游戏”。
- 手机宽度约 390px 可完整阅读并能点击所有入口。
- 视觉主色使用深海蓝黑、雾白、琥珀橙、少量青绿；避免当前全页高饱和霓虹彩卡堆叠。
- 所有交互控件保留可见焦点状态，减少动画时尊重 `prefers-reduced-motion`。

### Task 1: 建立视觉基线与页面结构

**Files:**
- Modify: `arcade.html`
- Modify: `index.html`

**Interfaces:**
- Consumes: 当前页面所有 `.cab[data-url]` 游戏入口。
- Produces: 统一的 `arcade.html` / `index.html` 视觉结构，所有入口保留原 `data-url`。

- [ ] **Step 1: 截取当前页面基线**

使用浏览器打开本地 `arcade.html` 与公网 `arcade.html`，记录移动端首屏、机台列表、页面长度和入口数量。

- [ ] **Step 2: 重写页面外壳**

将页面组织为：顶部导航、Hero 港口入口、精选机台、分类目录、底部营业状态。Hero 使用 CSS 绘制的港口月台与扫描灯，不引入外部图片。

- [ ] **Step 3: 重排现有机台**

保留每个 `.cab` 的 `data-url`，把最具代表性的游戏放进精选展台，其余机台按 `data-category` 分组；每台显示中文名、英文副标题、类型和明确的“进入机台”动作。

- [ ] **Step 4: 实现响应式和无障碍细节**

桌面使用宽屏双栏/网格，手机改为单栏；所有机台使用 button-like focus 状态；为减少动画和键盘操作提供对应样式。

- [ ] **Step 5: 运行结构检查**

检查 HTML 标签闭合、所有原入口 URL 保留、无外链资源、脚本语法和 `git diff --check`。

- [ ] **Step 6: 用浏览器截图审美复核**

分别检查 390px 手机和桌面宽度，确认首屏层次、文字可读性、无横向溢出和入口可点击。

- [ ] **Step 7: 提交并发布**

基于远端最新 `main` 提交视觉改造，推送后用 GitHub Pages HTTP、哈希和浏览器运行时复核。
